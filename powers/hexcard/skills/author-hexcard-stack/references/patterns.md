# Patterns

The 38 patterns of `draw_layer`'s `pattern` field and of the studio's paint tools, by pattern index. Each pattern is 8 rows of 8 characters, top row first. `#` is bit 1 (dark) and `.` is bit 0 (light); the leftmost character is the most significant bit of the row's byte.

Patterns are aligned to layer coordinates, not to the shape: the pixel at (x, y) takes the character at row `y mod 8`, column `x mod 8`. Two shapes drawn with the same pattern therefore line up where they touch.
